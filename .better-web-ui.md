## Design Context

### Users
TrustCode staff managing client relationships, projects, delivery, meetings, and document studios in the existing agency workspace.

### Brand Personality
Premium, modern, readable. Keep the original TrustCode logo and blue and white brand palette.

### Aesthetic Direction
The user explicitly requested the supplied Solvix dashboard reference: compact sidebar and toolbar, greeting with reporting controls, four compact metric cards, a wide activity chart with two stacked right-hand panels, and a full-width recent-records table. Match its density, thin borders, subtle gray section headers, small radii, and restrained typography.

### Implementation Defaults
Preserve existing Next.js 16, React 19, Tailwind 4, Manrope, Radix overlays, React Query, React Hook Form and native table components. Reuse existing APIs and navigation. No new chart dependency is needed for these SVG charts.

### Design Principles
- Match the supplied composition and spacing before adding decoration.
- Use blue for primary actions, chart series, and selected navigation; keep surfaces white.
- Display real workspace records and accurate empty states.
- Preserve working navigation, session boundaries, dark theme, keyboard access, and mobile usability.
- Reporting controls must change the displayed data or export it.
- Keep both navigation rails stable; scroll content independently. Document studios stay inside the app shell.
- Use branded dropdowns and quiet blue focus surfaces without dark focus rectangles.
- Auth follows the supplied split-layout reference, with a gentle looping contour background and responsive typing feedback.
- The animated six-slot code entry is a component preview only; retain the existing verification-link backend.
